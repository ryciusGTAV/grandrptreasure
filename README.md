GRANDRP TREASURE FINDER – GITHUB PAGES VERSIJA

Ši versija veikia kaip statinis tinklalapis. Python serverio ir START.bat nereikia.
Vaizdų apdorojimui naudojama OpenCV.js biblioteka iš docs.opencv.org, todėl pirmą kartą
atidarant puslapį būtinas interneto ryšys.

ĮKĖLIMAS Į GITHUB PAGES
1. Sukurk GitHub saugyklą (repository), pvz. grandrp-treasure-finder.
2. Įkelk index.html failą į saugyklos pagrindinį aplanką.
3. Atidaryk Settings → Pages.
4. „Build and deployment“ pasirink „Deploy from a branch“.
5. Pasirink branch „main“ ir aplanką „/(root)“, tada Save.
6. Palauk, kol GitHub pateiks svetainės adresą.

NAUDOJIMAS
1. Svetainėje pasirink visas galerijos nuotraukas vienu kartu.
2. Įklijuok telefono ekrano vaizdą su Ctrl+V arba pasirink failą.
3. Spausk „Ieškoti atitikmens“.

PRIVATUMAS IR APRIBOJIMAI
- Įkeltos galerijos nuotraukos apdorojamos tavo naršyklėje ir nesiunčiamos į serverį.
- Perkrovus puslapį galeriją reikės įkelti iš naujo.
- Nuotraukų poros nustatomos pagal failų pavadinimų natūralią tvarką (1–2, 3–4 ir t. t.).
- Automatinis apkarpymas remiasi atpažintais vaizdo požymiais; ne kiekviename vaizde jis
  gali tiksliai nustatyti telefono ekrane matytą vietovės ribą.
